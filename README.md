# Atelier Solenne — Glassmorphism Storefront Prototype

A single-file luxury e-commerce landing page and catalog: ladies leather bags, fabric pillow covers and leather laptop sleeves, styled with a frosted-glass aesthetic.

- Pure HTML + vanilla JavaScript in `index.html`
- Tailwind CSS (CDN), Lucide icons, Google Fonts (Cormorant Garamond + Plus Jakarta Sans)
- Category filters, live search, price sorting, quick-view modal and a slide-over cart (saved in localStorage)

Product names, prices and specs are mock data. Photography from [Unsplash](https://unsplash.com) under the Unsplash License, bundled in `images/`.
