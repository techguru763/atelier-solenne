# ENA · Eastern Narratives — B2B Showcase

A single-page wholesale showcase for ENA (Eastern Narratives): hand-embroidered cushion covers and handcrafted leather accessories, made by women artisans trained through the LEAPS Women Economic Empowerment Program.

- Product catalogue with collection filters, search, colourway swatches and a detail view
- No cart and no payments: buyers add designs to an enquiry and send a quote request
- Pure HTML + vanilla JavaScript in `index.html`, Tailwind CSS (CDN), Lucide icons, Google Fonts

To route enquiries to your team, set `CONTACT.email` and/or `CONTACT.whatsapp` near the top of the script in `index.html`.
